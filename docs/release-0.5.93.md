# AZOWL Personal 0.5.93

This release corrects the product spelling from AZWOL to AZOWL.

- Updates the window title, onboarding, workspace, update dialog and executable display metadata.
- Uses AZOWL Personal in the English and Korean product documentation.
- Keeps the existing icon, application ID, installation filenames, local data paths and public update feed.
- Does not change provider calls, permissions, organization enrollment, APIs or saved conversations.

The public Personal installer is not an organization/Harness installer. Organization installations must continue to use their separate managed channel. Older release notes retain the names used when those versions were published.

Downloads and installation still require explicit user actions. A published release does not mean another PC has installed it.
